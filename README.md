# Landing Page — Catálogo de Productos

## Descripción

Landing page comercial desarrollada para presentar y promocionar los productos de un emprendimiento familiar, brindándole presencia en internet y facilitando que potenciales clientes puedan conocer su catálogo.

El proyecto busca ofrecer una experiencia visual atractiva, intuitiva y adaptable a diferentes dispositivos, permitiendo visualizar los productos de manera organizada y acceder fácilmente a la información del emprendimiento.

## Objetivos

- Crear una presencia digital para el emprendimiento.
- Exhibir los productos de manera clara y organizada.
- Facilitar el acceso a la información comercial.
- Mejorar la experiencia de navegación de los usuarios.
- Ofrecer una interfaz adaptable a dispositivos móviles y de escritorio.

## Tecnologías utilizadas

- React
- JavaScript
- HTML5
- CSS3

## Características

- Interfaz web orientada a la presentación comercial.
- Organización visual de productos.
- Componentes reutilizables.
- Diseño responsive (si está implementado).
- Navegación sencilla e intuitiva.
